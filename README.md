# AI-OS
AI-OS macros for controllable AI programming

Final Document for new CLI Tool: AI-OS
Overview and Philosophy
AI-OS is a minimalist, powerful CLI designed specifically around macros and agents. It merges the deterministic, safe nature of traditional OS system calls with the creative, generative capacity of modern LLM-based agents. AI-OS eschews trendy, complex UI frameworks in favor of a streamlined CLI interface built on proven minimalism and clarity.

Agents are unpredictable but powerful; system calls are deterministic but limited. AI-OS lets you leverage both safely and efficiently through clearly defined slash commands and macros.

Philosophy:
"Abandon vibe coding—embrace AI engineering."
